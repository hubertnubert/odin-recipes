# odin-recipes

This is the initial project of The Odin Project’s Foundation Course.
Having covered the fundamentals of HTML—including text formatting, creating lists, managing links, and embedding images—the goal of this project is to build a dedicated recipe website. In line with the current curriculum, the site is constructed using pure HTML without any CSS styling to demonstrate a solid understanding of document structure and core elements.
